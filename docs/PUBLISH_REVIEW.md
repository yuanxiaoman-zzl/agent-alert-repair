# 发布审核范围

这是社区分享副本的审核说明，不是对原生产环境的安全认证。

## 原资料与公开内容的边界

- 原资料只读用于理解：独立采集、持久事件、邮件队列、有界模型调用、后续复查和独立看门狗。
- 不复制原生产目录、不导入其Git历史、不上传原配置、事故日志、聊天导出、邮件回执或任何认证文件。
- 核心参考代码在独立目录构造，样例为合成数据，不含实际服务器或任务身份。
- 原私有实现曾使用特定主机访问和更宽的执行权限；这些不能成为社区默认。公开适配器默认只读，只允许显式选择受限workspace-write，不提供无sandbox运行方式。

## 需要验证的关键行为

- 默认无外部调用；报警尚未被传输接受，不调用agent。
- 没有本任务授权、人工暂停、当前无法观测时，只通知。
- 同事件最多一次调用；每日预算共享；中断不重放不确定操作。
- 报告发送失败仅重试报告，不重跑修复。
- 模型声称恢复不等于独立验证；验证失败／不可用不报恢复。
- 超时信号只发给新建的修复进程组，不碰计算进程。
- 发布文件不包含原私有路径、个人邮箱、内网地址、会话／应用标识、密钥或认证文件。

## 本次验证的限制

隔离测试使用模拟通知与模型；没有发送邮件、调用付费模型、连接服务器或启动守护。没有将新参考实现伪装成原生产实测。仅有文档与参考组件，实际接入仍需用户为自己的主机权限、数据外传、状态采集和通知适配器验收。

运行锁与私有状态文件假定处于可信的本地目录，面向单主机协调；不提供跨主机共识、恶意本地用户隔离或崩溃一致性的生产级数据库保证。原子替换与文件fsync不能代替完整存储事务。出现无法确定的状态时应保留现场、人工核查，不复用episode或重置attempt来重跑。

## 发布前检查结果（2026-10-23）

- 21项隔离测试通过，覆盖通知顺序、授权隔离、人工暂停、不可观测、共享预算、全局锁、中断不重放、报告重试、模型超时与结构化报告。
- 逐文件检查公开目录；对原实现中的已知私有标识和已知邮件凭证做本地内存比对，未发现匹配，不输出这些原值。
- 模式检查覆盖个人路径、邮箱、内网地址、会话标识、应用标识、常见token格式和私钥头，未发现匹配。
- 仓库从独立目录新建，只提交明确列出的文档、合成JSON、参考代码和测试；不带入原仓库历史或运行产物。
- 静态检查与模式扫描不可能证明绝对不存在秘密；本次结论只限于本次提交的文件及已列检查。
